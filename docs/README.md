# Tavily Proxy 文档站 (Website)

> **注意**：本目录为派生同步产物。
> 权威源维护在 `tavily-proxy-docs/website/`，文档正文源维护在 `tavily-proxy-docs/manual/shared/`。
> 请勿在此处直接手改，改动后请运行 `tavily-proxy-docs/scripts/sync-website.sh` 刷新。

## 本地启动

```bash
pnpm install
pnpm dev      # 启动预览：http://localhost:4400
pnpm build    # 静态构建：产物输出至 dist/
```
